# 🎓 Advanced School Management System

A powerful and modern school management system built with **Laravel 12** and **FilamentPHP v3**. Designed to streamline academic, administrative, and financial operations for schools, colleges, and other educational institutions.

---

## 🔥 Core Features

### 📘 Academic Management

-   Manage academic sessions
-   Create classes, departments, sections, and shifts
-   Assign subjects and teacher designations

### 👨‍🎓 Student Management

-   Student admission system
-   Attendance tracking
-   Classrooms management
-   Printable student ID cards

### 👩‍🏫 Teacher Management

-   Add and manage teacher profiles
-   Assign teachers to classes
-   Track attendance
-   Generate printable teacher ID cards

### 🧪 Exam Management

-   Exam creation and scheduling
-   Marks entry interface
-   Report cards generation
-   Printable admit cards

### ⏰ Timetable Management

-   Create and manage class schedules

### 💰 Finance Management

-   Fee group creation and assignments
-   Discount and fine rules
-   Fee collection and payment tracking

### 📚 Library Management

-   Manage book inventory
-   Issue and return system for books

### 📊 Reporting

-   Attendance reports
-   Fee summary reports
-   Performance and exam analytics

### 📢 Communication Module

-   Send messages to user roles or custom users
-   Announcement system
-   Event management

### 🔐 Access Control

-   Role-based user permissions
-   User and admin management

### 💼 HR & Payroll

-   Define salary components and structures
-   Salary payment processing

---

## 🧩 Tech Stack

-   **Backend**: Laravel 12
-   **Admin Panel**: FilamentPHP v3
-   **Database**: MySQL
-   **UI**: Filament + TailwindCSS
-   **Print Support**: ID Card, Admit Card, Report Card as a Result Card
